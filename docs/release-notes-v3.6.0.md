# یادداشت انتشار v3.6.0 — تم «Aurora Premium»

## خلاصه

رابط کاربری سامانه بر اساس فایل پیوستِ کاربر (`aurora-theme.css` + سند پرامپت) به
تم **Aurora Premium** بازطراحی شد: زبان بصری **شیشه‌ای (Glassmorphism) + گرادیان
Aurora** با حالت شب پیش‌فرض و حالت روز هماهنگ — بدون هاردکد رنگ؛ همه‌چیز توکن‌محور.

## چه چیزهایی عوض شد

### توکن‌ها (DNA طراحی — دقیقاً مطابق پیوست)
- **شب (پیش‌فرض):** پس‌زمینهٔ `#050514 → #0f0c29 → #1a1342`، شیشهٔ `rgba(255,255,255,.06~.12)`
  با `backdrop-filter: blur(20px)`، متن `#f8fafc/#cbd5e1/#94a3b8`، اکسنت
  بنفش→صورتی `#a78bfa → #f472b6` و فیروزه‌ای `#38bdf8`، سایهٔ درخشان
  `0 8px 32px rgba(167,139,250,.30)`، انتقال `0.3s cubic-bezier(.4,0,.2,1)`.
- **روز:** پس‌زمینهٔ `#eef2f7/#e2e8f0/#cbd5e1`، اکسنت `#7c3aed → #db2777` و
  `#0284c7`، سایهٔ ملایم — همان توکن‌ها با مقادیر روز.
- شعاع گوشه‌ها مطابق پیوست: ۱۲/۱۸/۲۴px.
- توکن‌های جدید `--bg-deep/--bg-1/--bg-2`، `--glass-bg/--glass-border`،
  `--text-1/2/3`، `--accent-aurora/-2`، `--accent-3`، `--shadow-glow/--shadow-card`
  و `--transition-aurora` در هر دو تم تعریف شدند.

### کامپوننت‌ها
- **کارت‌ها:** حاشیهٔ گرادیانی بنفش→صورتی→فیروزه‌ای، کارت‌های آماری نوار گرادیانی
  ۳px در بالا + `translateY(-3px)` و درخشش روی hover.
- **دکمهٔ اصلی:** درخشش Aurora + بالاآمدن ۲px روی hover.
- **ورودی‌ها:** هالهٔ focus `0 0 0 4px rgba(167,139,250,.15)` در شب و معادل روز.
- **سایدبار حالت روز:** شیشهٔ سفید نیمه‌شفاف + blur (اصلاح مهم — قبلاً سایدبار در
  تم روز هم تیرهٔ هاردکد بود؛ حالا طبق §16 تم پیوست، سفید شیشه‌ای است).
- **گروه‌های سایدبار (v3.5.1):** از رنگ هاردکد به توکن تبدیل شد تا در هر دو تم
  درست بنشیند.
- **صفحهٔ ورود:** حلقهٔ چرخان و هاله‌ها با پالت Aurora + عنوان قهرمان با متن
  گرادیانی (`background-clip: text`).
- هاله‌های سحابی پس‌زمینه، نشان برند، انتخاب متن و اسکرول‌بار با پالت جدید.

## نکات فنی
- استراتژی اعمال: بازنویسی مقادیر توکن‌های موجود + افزودن توکن‌های Aurora؛ هیچ
  قاعدهٔ CSS موجود تکرار یا حذف نشد (کم‌ریسک‌ترین مسیر برای ~۴۰۰۰ خط استایل).
- فونت **Vazirmatn** (طبق الزام تم) — به‌جای CDN، از نسخهٔ self-hosted موجود
  استفاده می‌شود تا بستهٔ Portable بدون اینترنت هم کامل باشد.
- مکانیزم تغییر تم (دکمهٔ شب/روز + ذخیره در localStorage + اسکریپت no-flash پیش
  از رندر) از قبل مطابق تم پیوست بود و بدون تغییر ماند.
- تغییر صرفاً فرانت‌اند است؛ بدون تغییر دیتابیس و API.
