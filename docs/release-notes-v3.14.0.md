# یادداشت انتشار v3.14.0 — ورود یکگانه مطابق ثبت پرتال + آدرس رسمی جدید

## ۱) پیکربندی ورود یکپارچه (SSO) مطابق تصویر پرتال (درخواست کاربر)

پیکربندی SSO سامانه دقیقاً با فرم «افزودن / ویرایش سامانه» پرتال ورود یکپارچه
(:8086) هم‌تراز شد:

| فیلد پرتال | مقدار (تصویر کاربر) | پیکربندی S360 |
| --- | --- | --- |
| کلید سامانه (appKey) | `tahsilyar` | `S360_SSO_APP_KEY` (پیش‌فرض tahsilyar) |
| نام | `تحصیل‌یار۳۶۰` | `S360_SSO_APP_NAME_FA` |
| توضیح | `مشاوه تحصیلی، انتخاب رشت` | `S360_SSO_APP_DESCRIPTION` |
| Client ID در SSO | `tahsilyar360` | `S360_SSO_CLIENT_ID` (پیش‌فرض tahsilyar360 → SSO فعال است) |
| آدرس ورود (نقطه ورود OIDC) | `http://192.168.100.4:8093/` | `S360_SSO_FRONTEND_BASE` + ریدایرکت callback |
| آیکون / ترتیب | ⏰ / ۵ | `S360_SSO_APP_ICON` / `S360_SSO_APP_ORDER` |

- `/api/v1/auth/sso/config` اکنون بلوک `app` (کلید، نام، توضیح، آیکون، ترتیب،
  Client ID) و `entry_url` را برمی‌گرداند تا مقایسه با ثبت پرتال یک‌نگاهی باشد.
- صفحه ورود: دکمهٔ «🔐 ورود یکگانه — تحصیل‌یار۳۶۰» با زیرنویس
  «⏰ تحصیل‌یار۳۶۰ — کلید tahsilyar» نمایش داده می‌شود.
- کلاینت بدون Secret فقط-PKCE است: وقتی `S360_SSO_CLIENT_SECRET` خالی باشد،
  کلید `client_secret` در بدنهٔ تبادل توکن ارسال نمی‌شود (کلاینت عمومی OIDC).
- ریدایرکت callback: `http://192.168.100.4:8093/api/v1/auth/sso/callback` —
  مطابق «آدرس ورود» ثبت‌شده در پرتال.

## ۲) آدرس رسمی سامانه: http://192.168.100.4:8093/ (درخواست کاربر)

- اجراکنندهٔ پرتیبل (`portable/education_server.py`): پورت رسمی از **۸۰۸۴ به
  ۸۰۹۳** تغییر کرد (BIND_HOST روی 0.0.0.0 بود و ماند) تا سامانه روی
  `http://192.168.100.4:8093/` در شبکهٔ محلی در دسترس باشد.
- پیش‌فرض‌های `sso_redirect_uri` و `sso_frontend_base` روی همان آدرس تنظیم شد.

## ۳) راستی‌آزمایی

- **۲۳۹ تست پاس** (۳ تست جدید: مقادیر ثبت رسمی در `/auth/sso/config`، حذف
  `client_secret` خالی در تبادل توکن، آدرس رسمی در تنظیمات).
- تأیید E2E مرورگر روی `127.0.0.1:8093` با همان پیکربندی: پاسخ config دقیقاً
  مطابق تصویر (tahsilyar/تحصیل‌یار۳۶۰/tahsilyar360/⏰/۵) و دکمهٔ ورود یکگانه
  با نام ثبت‌شده روی صفحه ورود.
