# یادداشت انتشار v3.4.1 — پالایش یکپارچگی پایه‌یار۳۶۰

## خلاصه

این نسخه یک ریلیز پالایشی است: پس از استقرار موفق پایه‌یار۳۶۰ **v1.0.14** و نخستین
همگام‌سازی کامل واقعی با کلید API (۲۲۷ درس + ۳۸ نسخهٔ پیش‌نویس سرفصل در دیتابیس
سامانه)، ریز‌اشکالات گزارش‌شدهٔ نسخهٔ v3.4.0 برطرف شده و زیرساخت CI برای بذر دادهٔ
زندهٔ پایه‌یار در بستهٔ قابل حمل آماده شده است.

## تغییرات

### رفع اشکال
- **بنر و متادیتای نسخهٔ پرتیبل:** اجراکنندهٔ قابل حمل (`portable/education_server.py`)
  هنوز خود را «v3.2.2» معرفی می‌کرد و فایل VERSIONINFO ویندوز (`portable/version_info.txt`)
  هم نسخهٔ ۳.۲.۲ را نشان می‌داد — هر دو به ۳.۴.۱ به‌روزرسانی شدند؛ حالا با هر ریلیز،
  ثابت `VERSION` در اجراکننده منبع حقیقت است.
- **متن هشدار سرفصل‌های بی‌تطبیق:** پیام هشدار همگام‌سازی کاتالوگ به اشتباه به
  «رفع دامنهٔ split-courses» اشاره می‌کرد؛ این دامنه در سرویس مرجع v1.0.14 تعمیر شده
  و واکشی آن در نخستین همگام‌سازی واقعی HTTP 200 برگرداند. متن جدید واقعیت داده را
  توضیح می‌دهد: عنوان‌های OCR مجموعهٔ ۱۳۹۴ با نام‌گذاری درس‌یار هم‌ارز نیستند و اتصال
  با «اتصال خودکار سرفصل‌ها» در پنل پایه‌یار یا نگاشت دستی انجام می‌شود.
  (اندازه‌گیری روی دادهٔ واقعی: یکسان‌سازی نویسه‌های عربی/فارسی هیچ تطبیق جدیدی
  اضافه نمی‌کند؛ تطبیق واقعی ۵۸ عنوان از ۱۹۵ است و باقی از نظر داده‌ای بی‌همتاست.)

### زیرساخت CI
- گام اختیاری **بذر دادهٔ زندهٔ پایه‌یار در بیلد پرتیبل** اضافه شد:
  `backend/scripts/seed_payehyar.py` پس از seed دمو اجرا می‌شود و اگر repo secret
  `S360_PAYEHYAR_API_KEY` تنظیم شده باشد، کاتالوگ و دامنه‌های گسترش‌یافته را داخل
  `education.db` بذر می‌کند — بستهٔ قابل حمل بعدی با دادهٔ واقعی پایه‌یار تحویل می‌شود.
  بدون secret، گام با پیام رد می‌شود؛ شکست واکشی هرگز بیلد را نمی‌شکند (خروجی صفر)
  تا انتشار نسخه به دسترس‌پذیری سرویس مرجع در لحظهٔ build وابسته نباشد.
- سرصفحهٔ بستهٔ ZIP و یادداشت‌های خودکار ریلیز به v3.4.1 به‌روزرسانی شد.

## سازگاری

- بدون تغییر شِما و بدون تغییر قرارداد API داخلی؛ ارتقا از v3.4.0 با جایگزینی بستهٔ
  قابل حمل (دیتابیس `data/education.db` موجود دست‌نخورده می‌ماند و bootstrap تکمیلی
  روی آن اجرا می‌شود).
- ۳۱ تست پایه‌یار (`test_payehyar_catalog` + `test_payehyar_v340`) پاس است.

## نحوهٔ استفاده از همگام‌سازی (همان v3.4.0)

1. کلید API را در `.env` کنار `SmartEducation.exe` بگذارید:
   `S360_PAYEHYAR_API_KEY=...` (و در صورت نیاز `S360_PAYEHYAR_AUTO_SYNC=true`)
2. منو → صفحهٔ «همگام‌سازی پایه‌یار۳۶۰» → دکمهٔ «⟳ همگام‌سازی کامل کاتالوگ»
   یا «⇄ همگام‌سازی افزایشی»؛ همگام‌سازی خودکار هم هر ۳۰ دقیقه انجام می‌شود.
