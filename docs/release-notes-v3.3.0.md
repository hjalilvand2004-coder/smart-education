# یادداشت انتشار v3.3.0 — همگام‌سازی دروس و سرفصل‌ها از پایه‌یار۳۶۰

## خلاصه

قابلیت همگام‌سازی جدول دروس و سرفصل‌ها از سرویس مرکزی «پایه‌یار۳۶۰» (PayehYar360 — Shared Core & Master Data) اضافه شد. صفحه جدید «همگام‌سازی پایه‌یار» وضعیت اتصال زنده به سرویس مرجع، اجرای همگام‌سازی کامل/افزایشی، آمار رونوشت و تاریخچه اجراها را نشان می‌دهد.

## معماری و اصول

- منبع حقیقت دروس/سرفصل‌ها **پایه‌یار۳۶۰** است؛ دانشجو۳۶۰ فقط «رونوشت همگام‌شده» نگه می‌دارد (reference_id / reference_version / owner_system / last_synced_at / sync_state).
- **قاعده طلایی:** تغییر نسخه سرفصل مرجع هرگز بی‌صدا اعمال نمی‌شود؛ نسخه پیش‌نویس (source_kind=REFERENCE_SYNC) + وضعیت REVIEW_REQUIRED + پرچم بررسی نگاشت مفهومی ساخته می‌شود و نسخه مصوب/محتوا/شواهد به نسخه خود وفادار می‌مانند.
- **نرمال‌سازی دفاعی:** شکل دقیق پاسخ کاتالوگ پیکربندی‌محور است؛ چند شکل رایج (لیست خام، items/data، کلیدهای جایگزین مثل course_code/units، سرفصل متنی) پوشش داده می‌شود و رکوردهای نگاشت‌نشدنی به‌جای کرش، در warnings گزارش اجرا ثبت می‌شوند.
- **خطای احراز هویت قابل‌اقدام:** هر خطای سرویس مرجع (UNAUTHENTICATED / INSUFFICIENT_ROLE / …) با کد طبقه‌بندی و راهنمای فارسی دقیق (صدور کلید API، تنظیم متغیر، نقش‌های لازم) به UI می‌رسد؛ همگام‌سازی هرگز داده ساختگی واقعی‌نما تولید نمی‌کند.

## سرویس مقصد و احراز هویت (پروب واقعی ۲۰۲۶-۱۱-۲۳)

- آدرس پیش‌فرض: `S360_PAYEHYAR_BASE_URL=http://188.212.96.235:8094`
- مسیر رسمی اکوسیستم: `GET /api/v1/services/masterdata/{domain}` با هدر **X-API-Key** (کلید از بخش سرویس‌کلاینت‌های پایه‌یار صادر می‌شود) — `S360_PAYEHYAR_API_KEY`
- مسیر جایگزین حالت توسعه: هدر **X-Dev-User** با کاربر دارای نقش steward/tenant_admin — `S360_PAYEHYAR_DEV_USER`
- همگام‌سازی افزایشی: `GET /api/v1/sync/changes` (cursor) + ثبت نقطه در `POST /api/v1/sync/checkpoints`

## تغییرات فنی

### بک‌اند (FastAPI)
- `app/services/payehyar_client.py` (جدید): کلاینت httpx با transport تزریق‌پذیر برای تست، probe سه‌مرحله‌ای (openapi عمومی → طبقه‌بندی احراز هویت)، نگاشت خطا به PayehyarError با hint فارسی.
- `app/services/payehyar_catalog.py` (جدید): نرمال‌سازی کاتالوگ، upsert درس‌ها (ایجاد / پیوند درس محلی هم‌کد / به‌روزرسانی / بدون تغییر)، هم‌ترازسازی نسخه سرفصل با قاعده طلایی، لاگ اجرا.
- `app/models/journey.py`: جدول `masterdata_sync_logs` (حالت، وضعیت، آمار ایجاد/به‌روزرسانی/پیش‌نویس/بررسی، warnings، cursor، خطا، مدت).
- `app/api/v1/integration.py`: `POST /integration/payehyar/sync` (FULL/INCREMENTAL)، `GET /integration/payehyar/status`، `GET /integration/payehyar/logs` — فقط کارکنان آموزشی.
- ۱۴ تست جدید (`tests/test_payehyar_catalog.py`) با سرور mock: نرمال‌سازی چند شکل، طبقه‌بندی خطاها، idempotency (اجرای دوم بدون ایجاد تکراری)، پیوند درس هم‌کد، تغییر نسخه → بررسی استاد، RBAC.

### فرانت‌اند (React)
- صفحه `Payehyar.tsx` + مسیر `/payehyar` + آیتم ناوبری «همگام‌سازی پایه‌یار» برای کارکنان؛ کارت اتصال با نشان وضعیت و راهنمای اقدام، چهار کارت آمار، دکمه‌های همگام‌سازی کامل/افزایشی، جدول تاریخچه اجراها — RTL با تم دوگانه رصدخانه.

## پیکربندی

```env
S360_PAYEHYAR_BASE_URL=http://188.212.96.235:8094
S360_PAYEHYAR_API_KEY=          # از پایه‌یار۳۶۰ صادر کنید
S360_PAYEHYAR_DEV_USER=         # جایگزین حالت توسعه
S360_PAYEHYAR_TIMEOUT_SECONDS=8
```

تا پیش از تنظیم کلید، صفحه همگام‌سازی وضعیت «نیازمند کلید API» را با پیام واقعی سرویس مرجع و راهنمای دقیق نشان می‌دهد — این رفتار تست‌شده و موردانتظار است.
