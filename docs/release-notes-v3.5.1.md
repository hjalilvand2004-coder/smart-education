# یادداشت انتشار v3.5.1 — سایدبار دسته‌بندی‌شده

## خلاصه

ناوبری اصلی سامانه که با رشد قابلیت‌ها (به‌ویژه صفحه‌های MDM پایه‌یار۳۶۰ در v3.5.0)
طولانی و شلوغ شده بود، حالا **دسته‌بندی‌شده با گروه‌های بازشدنی** است: هر گروه با
کلیک باز می‌شود، زیرمجموعه‌هایش با خط راهنمای عمودی نمایش داده می‌شوند و
**گروهِ مسیر فعال به‌طور خودکار باز می‌ماند** تا همیشه معلوم باشد کجای سامانه هستید.

## دسته‌بندی ناوبری

| گروه | زیرمجموعه‌ها |
| --- | --- |
| آیتم‌های مستقل (همیشه بالا) | امروزِ من، درس‌ها |
| **یادگیری هوشمند** | محیط یادگیری، نقشه مفاهیم، کلینیک خطا، به من یاد بده، آمادگی آزمون، برنامه مطالعه، ابزارهای هوشمند |
| **آزمون و سنجش هوشمند** | کوییز‌ها و آزمون‌ها، سنجش تسلط *(دو صفحهٔ موجود که تا حالا در ناوبری نبودند)* |
| **تولید محتوا و تدریس** | استودیو محتوا، اقدام‌های استاد، امتیاز اساتید |
| **اطلاعات پایه (پایه‌یار۳۶۰)** | دروس یکتا، دروس تفکیکی، سرفصل دروس |
| **یکپارچه‌سازی و مدیریت** | برنامه‌یار۳۶۰، همگام‌سازی پایه‌یار، پنل مدیریت (فقط مدیر ارشد) |
| آیتم مستقل | گزارش‌ها |

## نکات فنی

- گروه‌ها بر اساس نقش/دسترسی کاربر ساخته می‌شوند (دانشجو فقط گروه‌های یادگیری و
  آزمون را می‌بیند؛ بخش‌های استاد/MDM/مدیریت فقط برای افراد مجاز رندر می‌شوند).
- در موبایل، ناوبری بالا همچنان **تخت و اسکرول‌شونده** است تا با یک لمس به همه‌جا
  دسترسی باشد؛ گروه‌بندی فقط در سایدبار دسکتاپ اعمال می‌شود.
- فلش باز/بسته با چرخش نرم، سازگار با RTL؛ لینک فعال با همان استایل قبلی
  هایلایت می‌شود و سرگروه آن نیز رنگ فعال می‌گیرد.
- تغییر صرفاً فرانت‌اند است (Layout.tsx + استایل)؛ بدون تغییر دیتابیس و API.
- یادداشت: «حضور و غیاب هوشمند» هنوز صفحه/ماژولی در سامانه ندارد؛ به محض
  اضافه‌شدن، گروه خودش را در همین ساختار می‌گیرد.
