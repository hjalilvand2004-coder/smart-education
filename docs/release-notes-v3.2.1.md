# یادداشت انتشار — نسخه ۳.۲.۱ «رفع serve فرانت‌اند در نسخه پرتیبل»

تاریخ انتشار: ۱۴۰۴/۹/۲ (۲۰۲۶-۱۱-۲۳)

## 🐞 رفع باگ اصلی: صفحه وب در exe پرتیبل باز نمی‌شد

علامت: اجرای `SmartEducation.exe` مرورگر را باز می‌کرد اما به‌جای سایت فقط
`{"detail": "Not Found"}` دیده می‌شد.

ریشه (دو لایه):

1. **نام متغیرهای محیطی لانچر اشتباه بود** — لانچر exe (میراث کد v2.x) متغیرهای
   `FRONTEND_DIST_DIR`، `DATABASE_URL` و `EXPORTS_DIR` را ست می‌کرد در حالی که
   اپ دانشجو۳۶۰ همهٔ تنظیمات را فقط با پیشوند `S360_` می‌خواند
   (`S360_FRONTEND_DIST`، `S360_DATABASE_URL`، ...). نتیجه: اپ اصلاً نمی‌دانست
   رابط کاربری کجاست و حتی دیتابیس بذرشده را هم نمی‌دید (دیتابیس خالی می‌ساخت).
2. **مسیر جایگزین توسعه‌ای در بسته وجود نداشت** — fallback قدیمی
   `parents[2]/frontend/dist` در چیدمان بستهٔ PyInstaller (onedir) به هیچ‌جا
   اشاره نمی‌کرد؛ دادهٔ واقعی در `<exe>/_internal/frontend_dist` بود.

اصلاحات:

- **`portable/education_server.py`**: همهٔ متغیرها با نام‌های صحیح `S360_*`:
  `S360_DATABASE_URL`، `S360_STORAGE_DIR`، `S360_FRONTEND_DIST`؛ متغیرهای
  بی‌اثر (`SCHEDULER_BASE_URL`، `SERVICE_BASE_URL`، `EXPORTS_DIR`) حذف شدند؛
  پیش‌فرض‌های SSO (`S360_SSO_REDIRECT_URI` و `S360_SSO_FRONTEND_BASE`) روی
  پورت واقعی اجرا ست می‌شوند؛ پیام‌های کنسول دقیق‌تر شد (مسیر رابط کاربری
  باندل‌شده + حساب‌های نمونه).
- **`backend/app/main.py`**: تابع جدید `_resolve_frontend_dist()` — یافتن
  build فرانت‌اند در همهٔ چیدمان‌ها به‌ترتیب: متغیر صریح → `sys._MEIPASS` →
  `<exe>/_internal/frontend_dist` → `<exe>/frontend_dist` → درخت سورس (توسعه).
  یعنی حتی اگر لانچر هم متغیر را ست نکند، exe مستقیماً (دابل‌کلیک) درست کار
  می‌کند (دفاع در عمق).

## 🧪 کیفیت و اثبات

- ۷ تست جدید (`tests/test_portable_spa.py`): resolver در حالت صریح/`_MEIPASS`/
  `_internal`/درخت سورس، نادیده‌گرفتن متغیر اشتباه، serve SPA با env لانچر، و
  حالت فقط-API. **مجموع: ۱۳۵ تست — همه سبز.**
- شبیه‌سازی کامل چیدمان exe به‌صورت لوکال: دیتابیس بذرشده + `frontend_dist`
  زیر `_internal` + env لانچر اصلاح‌شده → `GET /` صفحه RTL را می‌دهد (نه JSON)،
  `/courses` با fallback سرو می‌شود، ورود نمونه موفق است، مسیرهای API ناموجود
  همچنان JSON ۴۰۴ می‌دهند.
