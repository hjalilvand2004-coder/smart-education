# یادداشت انتشار v3.7.1 — کنتراست صفحهٔ ورود در هر دو تم

## مشکل (بازخورد کاربر)

در صفحهٔ ورود (`/login`)، ستون هیرو (متن‌ها، بج، لید، کارت‌های ویژگی، آمار و
پانویس) رنگ‌های ثابت «شب» داشت (متن سفید/بسیار روشن روی شیشهٔ روشن). نتیجه: در
تم روز، متن‌ها تقریباً نامرئی و بی‌کنتراست بودند.

## اصلاح

همهٔ رنگ‌های هاردکد ستون هیروی ورود به توکن‌های تم‌آگاه تبدیل شد (§ v3.7.1 در
`styles.css`) — در روز تیره/اشباع روی روشن و در شب روشن روی تیره:

| عنصر | قبلاً (ثابت) | اکنون (توکن‌محور) |
| --- | --- | --- |
| متن کلی هیرو | `#fff` | `var(--text)` |
| نام برند | گرادیان سفید→یاس | `--text → --accent-aurora-2` |
| بج بالا | شیشهٔ سفید + `#efeaff` | `--glass-bg/border + --text-2` |
| عنوان h1 | گرادیان بسیار روشن | `--text → --accent-aurora → --accent-aurora-2 → --accent-3` |
| لید | `#cfc7f5` | `--text-2` |
| کارت‌های ویژگی | شیشهٔ سفید ثابت | `--glass-bg/border` |
| تیتر/توضیح ویژگی | `#f4f0ff` / `#b6ace6` | `--text` / `--text-muted` |
| اعداد آمار | گرادیان پاستلی | `--accent-aurora → --accent-aurora-2` |
| لیبل آمار | `#9d94d4` | `--text-muted` |
| پانویس کارت | `#8f86d9` | `--text-muted` |

## تأیید

تست بصری هر ۴ حالت انجام شد: لندینگ روز/شب و ورود روز/شب — همهٔ متن‌ها در هر
دو تم کاملاً خوانا و متضاد با پس‌زمینه. ظاهر شبِ ورود دست‌نخورده ماند.

تغییر این نسخه فقط CSS/نسخه است؛ ۱۹۷ تست بک‌اند بدون تغییر پاس است.
